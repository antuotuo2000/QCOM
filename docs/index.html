Qualcomm（高通）

QCOM

NASDAQ · 半导体 · 无线通信 · AI芯片

我对高通的初步判断是：这是一家拥有真实技术壁垒、较强现金流和股东回报能力的半导体公司，但它面临手机市场成熟、自研芯片替代以及业务多元化能否成功的问题。

从巴菲特式价值投资角度看，高通值得研究，但不能简单因为 PE 低就认定它便宜。

我会按照你常用的 3–5 年投资框架，重点分析：

  • 公司究竟靠什么赚钱？
  • 它的护城河能维持多久？
  • 手机业务会不会持续衰退？
  • AI、汽车、PC 能否成为第二增长曲线？
  • 自由现金流和资本回报是否优秀？
  • 合理估值、安全边际和买入价格。

一、先看高通到底是一家什么公司

高通不是单纯的手机芯片公司。它实际上有两门非常重要的生意：

1. QCT：芯片业务

向手机、汽车、电脑、物联网设备厂商销售 Snapdragon 等芯片平台、基带、射频和连接产品。

(主要收入来源)

2. QTL：专利授权业务

通过通信标准必要专利等技术授权，向手机厂商收取专利许可费用。

(高利润业务)

这两项业务的商业模式完全不同：

对比QCT芯片业务QTL专利授权
收入来源卖芯片收取专利授权费
是否需要生产芯片需要供应链制造不需要
竞争强度较高相对较低
利润率中等偏高非常高
核心壁垒芯片技术、研发、生态专利组合、通信标准

我认为QTL是高通最值得珍惜的资产。

因为芯片行业需要不断研发、投入资本、面对竞争，而专利授权业务的边际成本相对较低。

三、高通的护城河在哪里？

我把它分成四个方面。

1. 通信专利：最强护城河

高通长期参与3G、4G、5G通信标准的研发和专利积累。

手机厂商即使使用其他公司的处理器，也可能需要获得高通相关专利授权。

这意味着：

  • 不一定购买高通芯片，也可能需要支付授权费用。
  • 高通可以同时从芯片和专利授权中赚钱。
  • 专利业务不完全依赖某一款手机芯片是否畅销。

2026财年QTL收入55.56亿美元，税前利润40.22亿美元，税前利润率约72%。

这是非常优秀的商业模式。

2. Snapdragon芯片技术

高通在以下领域有较强竞争力：

  • 手机SoC处理器。
  • 5G基带。
  • 射频前端。
  • AI手机端侧计算。
  • ARM架构PC处理器。
  • 汽车智能座舱和辅助驾驶芯片。

它的优势不是单纯某一颗芯片，而是长期积累的通信、低功耗、芯片设计和客户关系。

3. 研发投入

高通2026财年研发费用约102.07亿美元，占营收约23.7%。

这说明公司必须持续投入大量资金维持技术领先。

优点是技术壁垒较深，缺点是研发成本不会因为手机市场成熟而自动下降。

4. 客户关系和生态

高通服务大量手机厂商，覆盖苹果、三星以及中国手机品牌等客户。

但客户集中度也是风险。

苹果正在逐步转向自研基带，高通在苹果设备中的调制解调器份额面临下降压力。

这里我特别提醒两个问题：

第一，高通确实有不错的现金创造能力。

86.51亿美元自由现金流，说明公司不需要依靠不断融资维持经营。

第二，股票薪酬费用比较高。

2026财年股票薪酬费用达到34.52亿美元，占自由现金流约40%。

股票薪酬虽然不是当期现金支出，但会稀释股东权益。分析高通时不能只看回购金额，还要看回购之后的实际流通股数变化。

另外，2026财年现金及有价证券约76.81亿美元，债务约151.12亿美元，属于净负债状态。并不是没有财务风险，但考虑到现金流能力，暂时不构成我最担心的问题。

五、未来3–5年增长来自哪里？

这是决定高通未来估值的关键。

我把增长机会分为四个方向。

1. PC芯片

高通正在利用ARM架构进入Windows PC市场。

优势：低功耗、续航、端侧AI。

风险：英特尔、AMD以及苹果生态的竞争。

2. 汽车芯片

我认为这是高通最值得关注的第二增长曲线之一。

智能座舱、车载通信、ADAS辅助驾驶，都需要大量计算和连接能力。

2026财年汽车收入增长52%，已经体现出业务扩张。

3. IoT物联网

包括工业设备、智能家居、边缘计算和网络连接。

这类市场比较分散，但长期可能形成稳定收入。

4. AI数据中心

(重点观察)

高通已经与亚马逊宣布多代产品合作，拓展AI数据中心业务。

管理层重申2027财年数据中心收入目标50亿美元，并预计非手机业务收入同比增长超过60%。

但这是管理层目标，不是已经实现的收入。

我的判断：

增长业务3–5年潜力我的评价
手机芯片中低成熟市场
汽车芯片高已经有增长验证
PC芯片中高仍需抢占份额
IoT中高长期市场
AI数据中心高，但不确定有机会成为估值催化剂

我认为高通未来最大的机会，不是继续卖更多手机芯片，而是从手机通信芯片供应商变成更广泛的计算平台供应商。

但必须注意：不能提前把AI数据中心的成功全部计入今天的估值。

我认为最值得关注的三个竞争对手：

1. 苹果：

苹果逐步自研基带，会影响高通的手机芯片收入。

2. 联发科：

联发科是高通在安卓旗舰和中高端手机芯片领域最直接的竞争对手。

3. 英伟达：

如果高通希望进入AI数据中心，就必须面对英伟达已经建立的软硬件生态，以及其他定制芯片供应商的竞争。

1. 我采用什么估值方法？

我不建议直接使用高通2026年GAAP EPS的12.70美元估值，因为其中包含较大的税务收益影响。

我使用更保守的2026财年非GAAP EPS：10.54美元作为估值起点。

假设：

  • 初始EPS：10.54美元。
  • 持有期限：5年。
  • 要求年化回报：10%。
  • 未来退出PE：根据不同情景设定。
  • 不把尚未兑现的AI数据中心收入提前全部计入。

我的结论是：

  • 108美元：市场出现严重悲观预期，可能存在较大安全边际。
  • 149美元：基准情景下的价值投资参考价。
  • 171美元：低于乐观价值，但高于我的基准价值。
  • 200美元以上：需要较强的汽车、PC和AI数据中心增长来支撑。

九、管理层是否值得信任？

Cristiano Amon

高通CEO

他推动高通从传统手机芯片业务向汽车、PC、IoT和数据中心拓展。

我对管理层的评价是：战略方向正确，但还需要用结果证明执行能力。

值得肯定：

  • 没有只依赖手机芯片市场。
  • 在汽车领域已经实现明显收入增长。
  • 积极寻找AI数据中心的新市场。
  • 持续回购和分红。

需要观察：

  • 非手机业务能否真正成为主要增长来源。
  • 收购是否能够创造超过资本成本的回报。
  • 股票薪酬是否继续侵蚀股东价值。
  • 苹果业务流失后，能否补足利润缺口。

综合判断：值得长期跟踪，等待更好的买入价格。

我更愿意把高通看成一家有专利护城河、现金流不错，但正处于业务转型期的成熟半导体企业，而不是下一家英伟达。

如果我是长期价值投资者，我会重点跟踪这六项指标

指标我希望看到的变化

如果未来两三年汽车、PC、数据中心增长兑现，高通的估值可能获得重新评价；如果手机收入持续下降，而新业务不能补足，低PE可能长期存在。

十一、结合你之前的QCOM买入价

你之前提过以 170美元 买入过高通。如果目前仍然持有，那么现在约171美元的参考股价，意味着股价基本回到你的成本附近。

我的建议不是因为回本就卖出，而是重新审视持有逻辑：

  • 如果QTL专利业务稳定，汽车和数据中心业务持续兑现，可以继续观察。
  • 如果手机业务持续萎缩，非手机业务又无法补足利润，需要重新评估。
  • 不建议仅仅因为PE只有16倍就盲目加仓。

我最想提醒你的一点：高通的核心价值是通信专利和芯片设计能力，而不是AI概念。

如果你让我在高通和英伟达之间选择长期成长性，我倾向英伟达；如果比较成熟业务、专利壁垒和股东现金回报，高通有自己的优势。

接下来最值得做的是：把QCOM、AVGO、NVDA、AMD放在同一张价值投资估值表里，比较四家公司未来5年的自由现金流增长、合理PE和安全边际。
